## How It Works (User Side)

1. **User opens the link**
2. **Clicks "Start Installation"**
3. **Extension files load in memory** (NO downloads to PC)
4. **Browser's `chrome://extensions/` opens automatically**
5. **User clicks "Load unpacked"** and selects the extension folder
6. **✓ Done!** Extension is installed

## One-Time Setup

The first time:
```
Windows: C:\Users\YourName\AppData\Local\LaorORG-Netfix-Extension
Mac/Linux: ~/.local/share/LaorORG-Netfix-Extension
```

After that, the extension works permanently.
